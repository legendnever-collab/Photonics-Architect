# Layout & Routing Challenge — v0.3.0

Build → Identify Bottleneck → Edit Layout → Reroute → Test → Compare.

Level 1–3 retains the Engine-building experience: 1310-nm First 100G, ≤6.4-mm² Compact, four-corner Stable. Component alternatives are unlocked after Level 1 or available through exploration. Their requirements remain unchanged. Goal and NEXT ACTION are persistent beside Canvas; side panels and comparison dialog scroll internally. Completion needs Fresh Test; selection/hover do not invalidate a result, actual edits do.

Level 4 preserves the current Engine and records an RF Baseline when a valid 100G design is available. It targets the least comfortable lane by a heuristic ranking of delivered/required swing ratio and minimum-stage bandwidth ratio; these independent checks are not an Eye/BER margin. Select target Route or Driver directly from the Goal Card. Move/rotate the Driver or edit polyline Waypoints. A verified 25% length reduction, lower attenuation, error-free planning and maintained 100G complete the task at unchanged environment. Good ≤0.35-mm baselines are recognized explicitly; separate Practice is optional and preserves the Engine as an Original Snapshot.

Level 5 preserves Engine and Optical Start Snapshot, activates a fixed Keep-out and asks the player to complete all four optical outputs while avoiding it. Select the highlighted problem Route, Edit Route and move Waypoints around the rectangle. Orthogonal routing inserts visible elbows. Existing MZM, MRM and EAM examples all have valid solutions. Completion does not require a single Technology or Placement, nor shorter routes: detours increase propagation/bend loss and must still satisfy optical requirements.

Canvas distinguishes Optical cyan and RF orange, target glow, selected white/bright route, length labels, invalid red routes, draggable white anchors and clickable warning markers. Component invalid-placement preview updates during dragging. Manual anchors stay fixed; endpoints follow moved/rotated components. Reset is explicit, and history includes routes with component changes. Reroute / Simplify removes redundant points; it does not solve obstacle avoidance for the player.

Before / After uses actual re-solved designs with preserved original result records. It shows lane High/Low/Average/ER/OMA, RF length/swing/attenuation/BW, optical length/propagation/bend loss, driver/heater/bias power, footprint, local MRM temperature/detuning and error counts. Signed deltas show reductions and increases; they do not prescribe a winner. Environment, Brief or Solver mismatch disables direct comparison. Shortening RF by moving Driver can worsen MRM heating; route-only editing leaves thermal source positions unchanged.

VALID is educational requirement satisfaction. Crossings have no fabricated short/loss; unsupported same-domain physical crossings are warnings. Six snapshots and 100 history steps bound persistence size; JSON provides portable archives. Autosave restores level/progress/baseline/routes, but requires fresh Test. Enjoyment and comprehension need human playtesting; automated interaction proves behavior, not fun.
