# Product vision

Photonics Architect에서 플레이어는 고객의 Optical Engine을 공간 안에 직접 설계한다. Place → Connect → Run → Diagnose → Modify → Improve가 핵심이다. Component는 장식이 아니라 Optical/RF graph의 node다. Geometry는 경로 길이와 실제 모델 입력에 연결된다.

v0.1은 100G NRZ Transmitter 한 Mission만 완성한다. 여러 배치가 정답이 될 수 있으며 기능 충족 후 Power Margin과 Area efficiency를 개선한다. 후속 확장은 Modulator model과 Packet capability를 추가하는 방향이다.
