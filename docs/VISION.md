# Product vision

Photonics Architect에서 플레이어는 고객의 Optical Engine을 공간 안에 직접 설계한다. Specify → Select → Place → Connect → Test → Diagnose → Compare → Improve가 핵심이다. Component는 Optical/RF Graph의 실제 Node이며 Geometry는 Model 입력에 연결된다.

v0.1의 제작 경험을 보존하고 v0.2에서 같은 100G 고객 요구에 MZM/MRM/EAM과 맞는 Generic EIC를 선택하는 설계 자유도를 추가한다. 여러 설계가 유효할 수 있지만 면적, 전력, Optical Level, RF와 안정성의 희생을 비교해야 한다. 순서대로 누르는 유일한 정답보다 자기 Engine을 개선하는 경험을 지향한다.

실제 모델의 단순화·적용 범위와 근거를 확인 가능하게 유지한다. Source에 Confidential Data를 사용하지 않는다. 다음 기능은 실제 사용자의 플레이 경험을 확인한 후 선택한다.
