# Next development

The next priority is actual player feedback: goal comprehension, routing affordances and trade-off understanding. Review how easily players find a bottleneck and edit the route before adding more scale.

Future candidates: explicit orthogonal elbow orientation controls, grid obstacle-routing assistance with failure feedback, richer lane array, physical bend primitives with public model evidence, measured device fits and improved thermal kernel. Add public vendor parameters only within permitted scope and distinguish Reference / Assumed / Measured / Validated.
