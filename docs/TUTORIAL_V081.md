# Tutorial / v0.8.1

On first launch select **Tutorial Step 1** (or Skip). Tutorial has an independent Current Design and retained revisions.

1. **Place**: Add → Optical Input, Ge25 Data PD, TIA25 and Electrical Measurement. Tap Canvas to place each component.
2. **Connect**: Optical Input.out→GePD.in; GePD.current→TIA.current; TIA.out→Measurement.in. Touch Port selection and the Inspector Component/Port list are both available.
3. **Test**: Test runs the actual nominal25°C Receiver Screen. Bias, Profile, Bandwidth, Average/OMA and operating range all apply. Done requires a fresh successful result.

Done returns to the prior Workspace (new users return to Fast & Narrow Level1, empty). Goal details provide Skip. More→Tutorial/Help allows Replay; the prior Tutorial revision is preserved. Tutorial uses 25G NRZ and does not imply a production 200G or BER-qualified receiver. Each Track then teaches its actual compatible Rate and Architecture.
