# Handoff — Photonics Architect v0.4.0

Open `photonics-architect-v0.4.0.html` locally in a browser; no network assets or server needed. Desktop mouse controls and Levels1–5 are retained. On Mobile: Library → select → Canvas tap; tap Component → drag it or open Inspector for mm inputs and step arrows; Port → highlighted target or Inspector Component/Port list. Two fingers zoom/pan; explicit Pan mode uses one finger. Toolbar provides Undo/Redo, ±, Fit All, selection zoom, Reset and Snap. Goal details unfold when requested. Header Reference/Test remain accessible.

Reference button opens an optional full-screen Mobile viewer / Desktop modal. Fourteen verified examples span MZM/MRM/EAM; Compact excludes failing large MZM. Compare common-condition footprint/power/RF/optical/thermal trade-offs. Apply retains a protected original, deep-copies editable state, fits the new design, runs actual Solver and saves. Undo or Inspector Restore Previous Design returns the prior state. Backup survives Snapshot eviction; JSON includes portable referenceBackup. Saved results do not bypass Fresh Test on Resume.

Detailed executed results and limitations are in TEST_REPORT.md.

Limitations: real Android/iOS devices, native keyboard, Safari/Firefox/official Edge, platform-specific file-origin/eviction/quota, accessibility screen reader and enjoyment are unverified. Keyboard-reduced viewport is simulated. Canvas visual centerline is planning geometry with sharp optical corners, no foundry DRC/bend radius/full-wave/eye/BER. Reference is a valid educational example under displayed conditions, not unique optimum or measured device architecture. Individual UI reference backup failures are surfaced; if IndexedDB is unavailable, runtime Undo/backup and portable JSON remain available but cannot survive process closure without export. Viewer preview uses buttons plus scroll to zoom, not pinch; main design Canvas has actual pinch.
